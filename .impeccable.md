# Agent Quota Tracker visual context

The audience is a developer/power user who checks the widget peripherally throughout the day. The work is to understand weekly Codex quota without distraction. The voice is calm, tactile and precise.

Use fully solid surfaces inspired by Codex/OpenAI: warm white and cool graphite neutrals, comfortable text contrast, and restrained teal-green used rarely for status and data emphasis. Do not use transparency, Acrylic/Mica, glass, gradients, glow, visible outlines, nested cards or dashboard clutter. Hierarchy comes from whitespace, type scale, subtle tonal separation, symmetric outer padding and asymmetric internal alignment. Compact mode is essentially one weekly percentage. Detailed mode retains weekly quota, local analytics, forecast, model ranking and a small current-month daily usage chart. Settings is a solid tonal layer.

Typography embeds Source Sans 3 for display/values and Atkinson Hyperlegible Next for body/settings, both from Google Fonts under OFL. Lucide SVG source assets are included under `assets/lucide` under the ISC license.
